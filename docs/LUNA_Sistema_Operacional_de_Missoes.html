Arquitetura

Como o Sistema Funciona

A separação de responsabilidades é o que torna a Luna escalável. Cada peça tem um papel único e imutável.

Inteligência

Pertence ao LLM. Planeja, decide, escolhe Tools, interpreta resultados e cria estratégias.

Execução

Pertence à Luna. Envia prompts, executa Tools, espera respostas e continua o ciclo.

Especialização

Pertence aos Agentes. Cada um executa uma responsabilidade técnica específica.

Organização

Pertence às Missões. Definem o objetivo e a sequência ordenada de etapas (Pipeline).

Fluxo de Execução

O Ciclo da Luna

Este é o coração do sistema. Todo ciclo segue exatamente esta sequência. Nunca pula etapas. Nunca assume que terminou.

1

Iniciar Missão

O usuário define um objetivo. O Mission Engine carrega o Pipeline associado àquela missão. Ex: "Criar post Instagram sobre tendências de hoje".

2

Selecionar Step

O Pipeline Manager identifica a etapa atual. Cada Step tem um Prompt específico com apenas o contexto necessário para aquela etapa.

3

Enviar Prompt ao LLM

A Luna envia o Prompt da etapa para o LLM (Kimi). O Runtime envia apenas um Prompt por vez. Nunca envia dois ao mesmo tempo.

4

Aguardar Resposta

A Luna monitora continuamente a conversa. Depois de qualquer ação, ela NUNCA assume que terminou. Sempre espera.

5

Detectar Tool na Resposta

O LLM responde. A Luna verifica se a resposta contém uma chamada de Tool (JSON estruturado).

{
  "tool": "executarShell",
  "params": {
    "command": "npm run build"
  }
}
6

Executar Tool

Se houver Tool, a Luna a executa imediatamente. Pode ser: escrever arquivo, executar comando, abrir navegador, enviar mensagem, etc.

7

Retornar Resultado ao LLM

O resultado da execução é enviado de volta ao LLM. O ciclo reinicia: o LLM analisa e decide o próximo passo.

8

Step Concluído?

O LLM indica se a etapa foi concluída. Se não, o ciclo continua aguardando. Se sim, o Runtime marca como completed.

9

Próximo Step ou Finalizar

Se houver próximo Step no Pipeline, o Engine inicia automaticamente. Se não houver, a missão é encerrada e o resultado entregue ao usuário.

✓

Missão Entregue

O objetivo foi alcançado. Toda a execução foi logada. O usuário recebe o resultado final.

Agentes Especializados

O Exército da Luna

Cada Agente é um especialista em uma área. Eles não controlam o fluxo — apenas executam sua responsabilidade quando chamados.

🕵️

Trend Agent

Pesquisa tendências, analisa mercado e descobre o que está em alta no momento.

📸

Instagram Agent

Cria, revisa e publica conteúdo no Instagram. Gerencia legendas, hashtags e cronograma.

🎨

Image Agent

Gera imagens via IA, revisa qualidade visual e organiza biblioteca de mídia.

📁

Filesystem Agent

Lê, escreve e organiza arquivos no sistema. Cria pastas, move documentos, gerencia estrutura.

🌐

Browser Agent

Navega na web, clica em elementos, preenche formulários e captura screenshots.

💻

Shell Agent

Executa comandos no terminal. Instala dependências, faz deploy, roda scripts.

✈️

Telegram Agent

Envia mensagens, gerencia bots e categoriza conversas em chat, skill ou dashboard.

📊

Dashboard Agent

Cria e atualiza dashboards, relatórios e visualizações de dados em tempo real.

📧

Email Agent

Lê e-mails, classifica prioridade, gera rascunhos de resposta e gerencia caixa de entrada.

Automação via Cron Tasks

A Luna Trabalha Sozinha

A ideia central: tarefas agendadas disparam prompts específicos para a Luna, ativando agentes em sequência. Zero intervenção humana.

Como Funciona a Automação

1

Cron Task Agendada

Roda 3x ao dia (9h, 14h, 19h) e envia um prompt específico para o chat da Luna.

2

Prompt Ativa a Skill

O prompt instrui o LLM a executar uma skill específica (ex: "Pesquise trends de hoje").

3

Agentes em Cadeia

Um agente chama outro. Trend Agent → Image Agent → Instagram Agent. Tudo via Tools.

4

Entrega Automática

Resultado salvo em MD, imagem gerada, post publicado. Tudo logado e rastreável.

cron-luna.config

# Tarefas agendadas da Luna

# Formato: cron_expr | prompt_id | skill

0 9 * * * | "instagram-morning" | social-media

0 14 * * * | "instagram-afternoon" | social-media

0 19 * * * | "instagram-evening" | social-media

# Email — toda segunda 8h

0 8 * * 1 | "email-weekly-review" | email-agent

# Backup — todo dia 23h

0 23 * * * | "backup-daily" | filesystem

Exemplo Real: Post Instagram Automático às 9h

De 09:00 às 09:10 — 10 minutos, zero cliques humanos, post publicado.

Quem Faz o Quê

Separação de Responsabilidades

Responsabilidade Quem faz O que faz
🧠 Pensar LLM Planeja, decide, cria estratégias, interpreta resultados
⚙️ Executar Luna Runtime Envia prompts, executa Tools, espera, continua o ciclo
🎯 Especializar Agentes Executam tarefas técnicas específicas (imagem, shell, email...)
📋 Organizar Missões Definem objetivos e sequências de etapas (Pipelines)
🔄 Controlar fluxo Pipeline Define a ordem dos Steps e quando avançar
👤 Interagir Usuário Dá a missão, aprova, intervém se necessário

Vantagens

Por Que Essa Arquitetura Funciona

📈

Escalabilidade

Nova automação? Apenas crie um Pipeline. O Engine nunca muda. Missões infinitas, um só Runtime.

🔧

Manutenibilidade

Cada Step é independente. Erro em um não quebra os outros. Debug preciso e rápido.

👁️

Transparência

Você sabe exatamente em qual etapa a missão está. Nada é caixa-preta.

♻️

Reutilização

O mesmo Agente (ex: Git Agent) pode ser usado em qualquer missão. Sem duplicação.

🎮

Controle Humano

O usuário pode pausar, revisar ou modificar qualquer Step a qualquer momento.

🧩

Simplicidade

O Runtime tem uma única responsabilidade: executar e esperar. Quanto mais simples, mais escalável.

Glossário

Terminologia

LLM

Large Language Model — o "cérebro" do sistema (Kimi, GPT, Claude). Responsável por todo o raciocínio.

Runtime

Aplicação que executa código em tempo real — a "máquina" que conecta o LLM ao mundo.

Missão

Objetivo a ser alcançado — o "projeto" (ex: "Criar Landing Page", "Postar no Instagram").

Pipeline

Sequência ordenada de Steps — a "receita" que define a ordem de execução.

Step

Etapa individual de execução — o "passo" com um Prompt específico e uma única responsabilidade.

Prompt

Instrução enviada ao LLM — o "contexto" que define o que deve ser feito naquele Step.

Agente

Especialista em uma área — o "funcionário" que executa tarefas técnicas quando chamado.

Tool

Função executável pela Luna — a "ferramenta" que conecta o sistema ao mundo real.

Engine

Motor central do sistema — o "coração" que orquestra a execução de todas as missões.

Cron

Tarefa agendada que dispara automaticamente em horários definidos, sem intervenção humana.
